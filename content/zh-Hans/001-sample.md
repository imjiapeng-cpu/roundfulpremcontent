# 示例文章

这是一篇占位文章。它的存在是为了让校验脚本、清单生成器以及 iOS 应用在整个系统接通过程中都能拿到一篇真实的文章作为参考。

当你要发布第一篇正式文章时，把这份文件复制为 `content/zh-Hans/NNN-your-slug.md`，替换前置元数据里的字段，再重写正文。请不要在第一篇正式文章上线之前删掉这篇占位 —— 留一份已知可用的模板，以后调试 schema 改动会方便得多。

## 这里写什么

几段正文。常规 markdown 都可以用：标题、列表、**加粗**、*斜体*、`行内代码`、[链接](https://roundful.app)，以及 GFM 扩展如表格、任务列表。

## 一个小表格

| 字段 | 是否必填 | 说明 |
|---|---|---|
| `id` | 是 | 必须与文件名一致。 |
| `order` | 是 | 选择下一个 ≥ 100 的空闲编号。 |
| `updatedAt` | 是 | 每次修改正文都要更新。 |

就这些。推送到 `main`，构建脚本会跑起来，iOS 应用通常会在一个小时内拉到新内容。
